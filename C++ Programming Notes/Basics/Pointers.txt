% New operator
* The keywrd "new" can only be use for pointers specifically

* Using "new" we can creat a new value in a pointer variable
[syntax]
datatype* v_name = new                           datatype(value);

* To creat an array just use "[]"
instead of "()"

* The memory allocated using new must be explicitly deallocated using the delete keyword to avoid memory leaks.

* It is generally recommended to use smart pointers instead of raw pointers allocated with new to simplify memory management and avoid memory leaks.

% Delete operator
The keyword "delete" can be used to delete the value inside a pointer wich is dynamically operated 
[syntax]

*it will only delete the value not the variable

* to delete a block of memory like array or etc you have put "[]" infront of delelte keyword "delete[]"

% Pointers to derived class
* if you make a pointer_variable of base_class and make it point on the derived class.
* if you call a function wich contain same name in both base and derived class with the pointer it will call the fuction of base class due to late binding
[Note]
In C++, late binding, also known as dynamic binding, is a mechanism that determines which function definition to call at runtime based on the object's actual type. This is in contrast to early binding (static binding), where the function call is resolved by the compiler at compile time.
