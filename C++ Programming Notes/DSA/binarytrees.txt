# Tree:
    In Data Structures and Algorithms (DSA), a Tree is a non-linear, hierarchical data structure made up of nodes connected by 
    edges, where the topmost node is called the root and every other node is organized in parent–child relationships. Trees are 
    widely used in searching, sorting, hierarchical storage (like file systems), and efficient data retrieval.

# Diffrent Nodes:
    1.Root Node: The topmost node, with no parent.

    2.Parent Node: A node that has child nodes.

    3.Child Node: A node that descends from a parent.

    4.Leaf Node: A node with no children.

    5.Edge: The connection between two nodes.

    6.Level: Distance from the root (root is level 0).

    7.Height: Longest path from root to a leaf.

    8.Subtree: A node and all its descendants.

# Type of Trees:
    1.Binary tree: It have a most 2 child nodes.
    
    2.Binary search tree(BST): left child < parent < right child, its used for fast searching in Trees

    3.AVL Trees: self balancing BST , makes inssertion and searching efficient
    
    4.Red-black Tree: Balanced BST with color rules, used in database and compilers

    5.Heap(Binary Heap): A complete binary tree used for priority

    6.N-ary Tree: Each node can have n children, DOM file systems

    7.B-tree/B+ Tree: Multi ways Balanced tree

# Binary tree:
  A binary tree is a hierarchical data structure where each node has at most two children — a left child and a right child. It’s one of the most fundamental structures 
  in computer science, widely used in searching, sorting, and representing hierarchical data.

    🔑 Properties
    Maximum nodes at level L = 2𝐿

    Maximum nodes in a tree of height H = 2𝐻+1−1

    Minimum height for N nodes = ⌊log 2𝑁⌋

    Leaf nodes = internal nodes with 2 children + 1 (in a full binary tree)


# Creating a Binary Tree:

    '''class Node{
  public:
    int data;
    Node* left;
    Node* right;

    Node(int val){data = val; left = right = NULL;}
};

static int idx = -1;
Node* buildNode(vector<int> preorder)
{
  idx++;

  if(preorder[idx] == -1)
  {
    return NULL;
  }
  Node* root = new Node(preorder[idx]);

  root->left = buildNode(preorder);
  root->right = buildNode(preorder);

  return root;
}
'''

# Tree Traversal:

    There are totale 4 ways to travser a binary tree:
        3 are recursion based:
            1.Preorder
            2.Inorder
            3.Postorder
        
        1 is iterative based:
            1.level order


    1.Preorder traversal(root,left,right):
        Visit the root first, then traverse the left subtree, then the right subtree.

             4
            / \
           2   6
          / \ / \
         1  3 5  7

        Preorder → 4 2 1 3 6 5 7

        Code:
            void preorder(Node* root)
            {
            if(root == NULL)
            {
                return;
            }

            cout<<root->data<<", ";

            preorder(root->left);
            preorder(root->right);
            }

    2.Inorder traversal(left,root,right):
        Traverse the left subtree, then visit the root, then the right subtree.
        
            4
           / \
          2   6
         / \ / \
        1  3 5  7

        Inorder → 1 2 3 4 5 6 7

        Code:        
            void inorder(Node* root)
            {
            if(root == NULL)
            {
                return;
            }

            inorder(root->left);
            cout<<root->data<<", ";
            inorder(root->right);
            }

    3.Postorder traversal(left,right,root):
        Traverse the left subtree, then the right subtree, and finally visit the root.

            4
           / \
          2   6
         / \ / \
        1  3 5  7

        Postorder → 1 3 2 5 7 6 4

        Code:                       
            void postorder(Node* root)
            {
            if(root == NULL)
            {
                return;
            }

            postorder(root->left);
            postorder(root->right);
            cout<<root->data<<", ";
            }
    
    4.Level order traversal:
        It’s a Breadth‑First Search (BFS) technique.You visit nodes level by level, starting from the root, then all nodes at level 1, then level 2, and so on.

         4
        / \
       2   6
      / \ / \
     1  3 5  7

     Level Order Traversal -> 4 2 6 1 3 5 7

     Code:
        void levelorder(Node* root)
        {
            queue<Node*> q;

            q.push(root);

            while(q.size()>0){
                Node* curr = q.front();
                q.pop();

                cout<<curr->data<<" ";

                if(curr->left != NULL)
                {
                q.push(curr->left);
                }
                if(curr->right != NULL)
                {
                q.push(curr->right);
                }
            }
            cout<<endl;
        }
