%Exception handling in OOPs
1.Exception(Error)=An exception is                   an unexpected problem that arises during the execution of a code and our prgram terminates suddenlly with an error/issue.
% Keywords
1.try=It repersents a block of code that may through a exception placed inside the try block.

[syntax]
try
{
 //code
}

2.catch=It repersents a block of code that is executed when a particular exception is thrown from the try block.

[syntax]
try{}catch(const char prointer_variable)
{
 cout<<your message;
}

[Note]
1.there could be one or more than one catch block after a try.
2. you can call make the defoult catch block like this 
"catch(...){//code}"

3.thow=Any exception in c++ can be thrown using the "throw" keyword.

[syntax]
throw "message";

[Note]
After throwing an exception the program will be terminated immediately.
