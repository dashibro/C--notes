* To write a file you have to create an obj from "ofstream" class

% Opening a file
you can open a file in 2 ways:
1.obj_name.open("file_name.ext");
2.constructor:
obj_name("file_name.ext");
%Example code for reading a file
  ifstream file;
  file.open("temp.txt");
  char a;
  file>>a;
  while(!file.eof())
    {
      file>>a;
      cout<<a;
    }
  file.close();
%Example code for writing in a file
  ofstream file;
  file.open("temp.txt");
  file<<"hello world";
  file.close();
