% Iterators in STL
In C++, an iterator is like a pointer that points to an element within a container (like a vector, list, or array). It's a generic concept that allows you to traverse through the elements of a container.

% Key Points:
 * Generic: Iterators can be used with different container types.
 
 * Pointer-like: They provide similar operations to pointers (increment, decrement, dereference).
 
 * Traversal: They are used to iterate over elements in a container.
 
% Types of Iterators:
 * Input iterators: Can read elements only once.
 
 * Output iterators: Can write elements only once.
 
 * Forward iterators: Can read elements multiple times and move forward.
 
 * Bidirectional iterators: Can move forward and backward.
 
 * Random access iterators: Can access elements directly using an offset.
 $
[Example]
#include <iostream>
#include <vector>
int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5};
// Using iterators to print elements
    std::vector<int>::iterator it;
    for (it = numbers.begin(); it != numbers.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << std::endl;
// Using range-based for loop (C++11 and later)
    for (int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
return 0;
}

%Explanation
 * We create a vector numbers with elements 1 to 5.
 
 * We declare an iterator it of type std::vector<int>::iterator.
 
 * The begin() function returns an iterator pointing to the first element, and end() returns an iterator pointing to the position after the last element.
 
 * The for loop iterates through the vector using the iterator.
 * The *it dereferences the iterator to access the current element.
 
 * The range-based for loop is a more convenient way to iterate over containers.
